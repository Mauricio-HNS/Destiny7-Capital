# Destiny7 Capital

Autonomous AI company for financial market simulation and trading research.

## Vision

A virtual financial company where autonomous AI agents operate as employees: researching markets, developing strategies, managing portfolios, controlling risk, and making decisions in a living virtual office.

## Architecture

- Python — AI agents, quantitative research and simulation
- C# / .NET — financial core, risk, portfolio and execution engines
- TypeScript / React / Next.js — command center and visual office
- PostgreSQL — persistent state, decisions, portfolios and history
- Three.js — interactive virtual office

## Development principle

Every visual element must represent real application state. The office is not a decorative animation: agents, desks, screens, meetings, profits, losses and organizational growth are driven by the simulation.

## Safety

The initial system uses simulated capital and paper trading. Real-money execution is a future stage requiring appropriate controls, broker integration and regulatory review.
